# StillRelay 0.2.0 — Little agents. Shared progress.

A finds the clue. B builds the fix. C checks the work. StillRelay keeps their progress in one shared notebook, while the noisy logs stay with the worker.

Formerly Shared Task State. The repository URL, package names, CLI commands and MCP binding names stay the same.

## What the crew can do

- Delegate quietly and check progress at intervals with the optional `silent-delegation` Skill.
- Link a task to its exact executor/run, then inspect several tasks in one read-only supervision snapshot.
- Run an explicit local command under a task lease, with local stdout/stderr, heartbeats and a recorded exit result. Reconnecting controllers can find the logs through the saved reference.
- Reverse controller/worker roles across tasks. Three, six and seven MCP participants were tested; participant count is not hard-coded.

The command wrapper is foreground. Your existing authorized executor handles background work; MCP does not start arbitrary commands or wake sleeping agents. Worker completion still needs independent acceptance.

## Measured, with the small print

Nine deterministic trials, two MCP clients, three output-volume cases: supervisor-visible tool payloads fell by 11.23%, 46.97% and 89.52%. The quiet mode kept the same state checks and skipped full-log reads.

These are `o200k_base` payload counts, **not total model-token or billing savings**. No model inference was used, and worker traffic is counted separately. [Method](../../benchmarks/README.md) · [Raw results](../../benchmarks/results/2026-10-23/summary.md)

## Keep the notebook tidy

Built-in credential protection works without Betterleaks. It covers recognizable provider tokens, password/secret fields, authorization credentials, private keys and URL credentials. It does **not** comprehensively redact email, phone numbers or arbitrary personal information. Keep private records and raw logs out of shared state. An optional offline scanner can add checks; once configured, scanner failures block operations.

## Install or update

The MCP transport remains local stdio; no port or hosted service is added. Use the [MCP guide](../../references/mcp.md) and [delegation guide](../../references/delegation.md). Only initialize a new installation; existing users join their existing config and state UUID. Pin a reviewed release commit when updating.

Core regression tests: 65 passed. Installed MCP/lifecycle tests: 37 passed, including real command workers and 3/6/7-client cohorts. These tests do not establish model instruction-following, every client UI, or private Host deployment. Independent review is still pending for this draft.

The private Mac Host, state-retention design and production capacity are unchanged. Roll back the installed package to the previous pinned commit; preserve state and history rather than replacing newer work with an old database.

# StillRelay 0.2.0 — 小小 agent，一起把事情做好。

A 找線索，B 動手做，C 幫忙檢查。StillRelay 用同一本筆記維護進度，詳細日誌留在工作者那邊。前身是 Shared Task State，原有網址、套件、命令與 MCP 連線名稱保留。

這次加入選用的靜默委派 Skill、確切執行關聯、批次唯讀監督，以及管理心跳與結束結果的本機命令接合層。角色跟著任務走，A 派工給 B 的同時，也可以執行 B 的另一份任務；已測試三、六、七個 MCP 參與者，沒有把人數寫死。

靜默仍會間隔檢查進度與抽查證據，完成後也要獨立驗收。命令接合層以前景執行，背景派工交給既有的授權執行器；MCP 不會替休眠 agent 設鬧鐘。

九次實驗的派工者工具內容，分別減少 11.23%、46.97%、89.52%。這是相同狀態檢查下省去完整日誌讀取的差異，**不是整體模型 token 或帳單節省**，也沒有呼叫模型。[實驗說明](../../benchmarks/README.zh-TW.md)

沒裝 Betterleaks 也有現有憑證保護；Email、電話與自由文字個資目前沒有全面遮罩。只保存已確認進展與證據位置，原始日誌和私人資料留在共用狀態之外。離線掃描器是選配，設定後失敗即阻擋操作。

核心 65 項、已安裝 MCP／生命週期 37 項測試通過。草稿仍待獨立審查；沒有宣稱模型遵循 Skill、所有用戶端介面或正式 Host 已驗證。本次不改正式 Host、歷史保存設計或模型容量。升級與回滾請依[接入說明](../../references/mcp.zh-TW.md)與[委派指南](../../references/delegation.zh-TW.md)，保留現有設定、狀態身分與歷史。
