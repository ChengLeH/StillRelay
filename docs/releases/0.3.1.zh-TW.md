# StillRelay 0.3.1 — 換對話也接得上的獨立審查

[English](0.3.1.md)

StillRelay 0.3.1 讓獨立審查能跨對話、跨 agent 接續。工作者完成後，其他審查者可以稍後接手，不必仰賴同一段對話記得誰查過什麼。

## 這次修正了什麼

- 新任務會把審查者、執行器與執行編號的綁定、租約世代、檢查點及審查結果保存在任務歷史。
- 審查中斷後，必須先確認上一個審查執行已停止才能續接。續接會輪替審查租約，舊審查者就不能再寫入新一輪結果。
- 審查結果會綁定目前工作者的世代、完成修訂及已檢查輸出的指紋。工作結果改變或審查已過期時，不能沿用舊結果驗收。
- 新任務必須先由另一位審查者完成審查，才可驗收。審查通過後，可由工作者或非審查者的其他參與者驗收。既有任務在明確呼叫 `review_start` 前，仍保留原本的驗收流程。

## 信任範圍

StillRelay 會記錄審查者與審查結果，但不會啟動子代理、不驗證執行器身分，也不能證明 Host 建立了隔離的審查環境。Host 必須自行啟動全新的審查者。紀錄為通過只代表留下一筆審查結果，不保證成果正確。心跳代表聯絡，不代表進度或程序已停止。

## 升級

本版把審查欄位加入既有任務資料與歷史紀錄，不改 SQLite 資料表結構，也不需要資料庫遷移。沿用原本的設定與 state identity；既有任務資料不會被替換。

從 GitHub 安裝並固定在此版本：

```sh
uv tool install --reinstall 'git+https://github.com/ChengLeH/StillRelay@v0.3.1'
```

套件名稱、MCP 工具及用戶端連線設定維持不變。本次不包含私人 Host 部署。專案從 GitHub 發布，不發布到 PyPI。

## 驗證結果

GitHub Actions [run 40050665455](https://github.com/ChengLeH/StillRelay/actions/runs/40050665455) 已通過 macOS、Linux、Windows 與 Python 3.10、3.14 的六組測試，涵蓋獨立審查變更。每組都執行標準函式庫測試、安裝 MCP 套件，並測試 MCP 工具與 stdio 傳輸。
