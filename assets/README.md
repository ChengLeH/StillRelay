# StillRelay hero

`stillrelay-hero.png` is the original project banner, generated with the built-in image generation tool and selected after visual inspection.

Prompt: Cute flat 2D editorial app advertisement, cream background, dark ink outlines, lavender courier, coral maker and mint star helper cooperating around one shared notebook. Exact lettering “StillRelay”, “Little agents. Shared progress.” and “On it!” Playful rounded typography, subtle print texture, no photorealism, glass, 3D, model logos, metrics or watermark. Wide 2:1 composition. Three characters illustrate the tested scenario, not an agent limit.
